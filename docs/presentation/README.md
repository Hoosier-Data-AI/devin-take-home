# Screen-share package

These self-contained HTML files use a consistent visual language adapted from
Cognition's public website: warm neutral surfaces, blue accents, hairline
structure, numbered sections, restrained typography, and dense editorial layouts.
They require no server, package manager, or network connection.

Recommended presentation order:

1. `vp-presentation.html` — five-minute narrative and screen-share cues.
2. The running workbench — show one workflow and the Platform overview.
3. `app-accelerator-demo.html` — exact Generate → Enforce → Connect talk track.
4. `build-vs-buy-brief.html` — detailed comparison and 90-day decision gate.

`key-decisions.html` is the one-page written deliverable. Its print layout is
designed to fit one A4 portrait page.

Each HTML document supports light and dark themes, narrow screens, keyboard
navigation, and printing. The materials are take-home collateral rather than
official Cognition brand assets.
