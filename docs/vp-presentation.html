Build versus buy

What we'd need to run these ourselves

Owned codeYou can tailor KYC rules and UX, review changes in git, and test them. Engineers must maintain each app and the common code.
Production accessYou'll need SSO, group mapping, user provisioning, and a security review before using real customer data.
OperationsYour team will handle deployment, secrets, monitoring, backups, incidents, and support. Power Apps supplies platform services; you still configure your apps.

We still need to test real integrations and work through the operating costs before choosing this route.

Proposed 90-day pilot

Build two new apps while the existing ones stay put.

  1. Weeks 1–2Check app usage, license terms, integrations, support load, and security requirements.
  2. Weeks 2–5Add SSO, deployment, monitoring, backups, and an on-call owner to the prototype foundation.
  3. Weeks 5–10Use Devin to help build one straightforward app and one with a real integration. Track engineering and support time.
  4. Weeks 11–13Review security, reliability, and three-year cost. Count license savings only where the contract allows them.

If the cost and operating burden make sense, move apps gradually. If they don't, keep Power Apps for the routine work and use Devin for custom apps, extensions, and tests.
